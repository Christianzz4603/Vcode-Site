Questions

What is Vcode based on?

Vcode is a modified version of Squircle CE by Blacksquircle and its contributors. It adds new languages, keyword suggestions, a new look and a build pipeline. The original license and notices are kept.

Will it replace Squircle CE?

No. Vcode uses its own app id (com.vcode.studio), so both apps can be installed side by side.

Is it free?

Yes. Vcode is free and open source under the Apache License 2.0.

Android will not update over my old build. Why?

Builds are signed with a temporary key unless a fixed release key is configured, and Android refuses updates signed with a different key. If that happens, back up your files, uninstall the old build and install the new one.

Can I change how it looks?

Yes. Open Settings, then Application, then Color scheme, and pick one of 15 themes. In Settings, then Editor, you can also change the cursor style, smooth cursor animation, font ligatures and auto save delay.

Which Android versions are supported?

Android 7.0 (API 24) and newer.
