Features

Everything you need to code on the go

A focused editor and file manager, with the tools you expect from a desktop IDE.

IntelliSense

Suggestions for JavaScript, TypeScript, Kotlin, Java, Python, HTML, Android XML and shell, plus the words already in your file. Type imp, tap import.

Run and Output panel

Problems, Output, Preview and AI tabs in a bottom panel you can resize or open full screen. Run JavaScript and shell in the app, or send a command to Termux.

AI assistant

Ask about your code in the AI tab, with one-tap Explain, Fix problems and Refactor. Answers stream in, and you can copy them or insert code at the cursor. Powered by OpenRouter with your own API key.

Tools bar

Run, Termux, Preview, Output, Problems, AI, Full screen and Hide, right above the symbol keys. Drag to reorder, hide what you do not use.

49 languages

Syntax highlighting for Kotlin, Java, Python, Swift, Rust, Go, TypeScript, SQL and many more.

15 themes

VS Code style themes: Dark+, Light+, One Dark, GitHub Dark, Dracula and more.

Plugins

Add themes, keywords and file types with data-only plugins. A plugin contains no code.

Git integration

Commit, push, pull and manage branches without leaving the editor.

Local and remote files

A built-in file manager with SFTP and FTP(S) support.

Never lose work

Auto save with an optional delay. Undo and redo survive an app restart.

FAQ

Questions

What is Vcode based on?

Vcode is a modified version of Squircle CE by Blacksquircle and its contributors. It adds new languages, keyword suggestions, a new look and a build pipeline. The original license and notices are kept.

Will it replace Squircle CE?

No. Vcode uses its own app id (com.vcode.studio), so both apps can be installed side by side.

Is it free?

Yes. Vcode is free and open source under the Apache License 2.0.

How does Run in Termux work?

Vcode does not bundle Termux. It hands the command to the real Termux app. Install Termux, add allow-external-apps = true to ~/.termux/termux.properties, restart Termux, and allow Vcode the Termux run-commands permission if Android asks. Details are in the documentation.

How does the AI assistant work?

It uses OpenRouter with an API key that you add in Settings, then AI assistant. You pay your own OpenRouter usage. The key is stored in the app settings on your device without extra encryption, so use a key with a spending limit.

Android will not update over my old build. Why?

Builds before version 1.5.1 were each signed with a different temporary key, so Android refuses to update over them ("conflict with an existing package"). Uninstall the old build once (back up your files first) and install the new one. From 1.5.1 on, every build is signed with the same key, so updates install over each other.

Can I change how it looks?

Yes. Open Settings, then Application, then Color scheme, and pick one of 15 themes. In Settings, then Editor, you can also change the cursor style, smooth cursor animation, font ligatures and auto save delay.

Which Android versions are supported?

Android 7.0 (API 24) and newer.
