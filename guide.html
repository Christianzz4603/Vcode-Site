Getting started

From download to your first edit in a few minutes. For every setting and the plugin format, see the documentation.

  1. Download the app. Tap Download APK (or get Vcode-foss.apk from the releases page).
  2. Install it. Open the file. If Android asks, allow your browser or file manager to install unknown apps, then tap Install.
  3. Open Vcode and allow file access. This lets you open and save files on your phone.
  4. Open or create a file. Use the file manager to browse your folders and tap a file to open it. Every open file gets a tab at the top.
  5. Edit. Start typing. Suggestions appear as you type: type imp and tap import to complete it. A blue dot on a tab means unsaved changes.
  6. Pick a theme. Go to Settings > Application > Color scheme and choose one of 15 themes. Preview them first.
  7. Tune the editor. In Settings > Editor you can turn on auto save, choose how soon it saves, and change the cursor style, smooth cursor animation and font ligatures.
  8. Add plugins. Download a plugin from the plugins page, then open Settings > Plugins > Install plugin and pick the file.

Tips

  • Tap the selected tab for a menu to close the tab, close others or close all.
  • Pinch to zoom the text if pinch zoom is enabled in the editor settings.
  • Vcode installs next to Squircle CE, so you can keep both.

Troubleshooting

Android will not update my old Vcode build

Builds are signed with a temporary key unless a fixed key is configured, and Android blocks updates signed with a different key. Back up your files, uninstall the old build and install the new one.

A plugin was rejected

The message names the problem. The most common one is a theme file that is missing a color. Compare it with the list of required colors.

A plugin theme disappeared

Themes from a plugin are only available while the plugin is installed and turned on. If you remove it while it is the active theme, Vcode switches back to Vcode Dark.

Keyword suggestions or file types from a plugin do not show up

They apply to files you open after installing or turning on the plugin. Close the file and open it again.
