# VCode Cloudflare Page

Static landing page for VCode.

## Deploy on Cloudflare Pages

This is a framework-free static site. Cloudflare Pages can deploy it directly with `index.html` at the project root. Use the `main` branch and no build step (or `exit 0` if the dashboard requires a build command).

The page automatically checks the VCode GitHub repository for its latest release and updates the release information/download button.
